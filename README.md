# Customer Churn Analysis using Power BI

## 📌 Project Overview

Customer Churn Analysis is a data analytics project focused on understanding customer retention and identifying factors that influence customers to leave a telecom service provider.

Using Power BI, this project transforms customer data into meaningful insights through data cleaning, KPI tracking, interactive visualizations, and churn analysis.

The objective is to help businesses understand customer behavior, identify churn patterns, and develop effective customer retention strategies.

## 🎯 Project Objectives

- Analyze customer churn and retention patterns.
- Identify customer segments with higher churn rates.
- Understand the impact of contract types, payment methods, and internet services on churn.
- Track key performance indicators using an interactive dashboard.
- Generate actionable insights to support customer retention.

## 📂 Dataset

- **Dataset:** Telco Customer Churn
- **Source:** [Kaggle – Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)
- **Domain:** Telecommunications
- **Data Includes:** Customer demographics, tenure, contract details, internet services, payment methods, monthly charges, total charges, and churn status.

## 🛠️ Tools and Technologies

- **Power BI Desktop** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – KPI calculations and measures
- **Data Visualization** – Charts, KPI cards, and interactive slicers

## ⚙️ Project Workflow

1. **Data Collection:** Imported the Telco Customer Churn dataset.
2. **Data Cleaning:** Cleaned and prepared approximately 7,000 customer records, handling missing values and checking data consistency.
3. **Data Transformation:** Prepared relevant columns and data types for analysis.
4. **DAX Calculations:** Created measures to track customer count, churned customers, retained customers, and churn rate.
5. **Dashboard Development:** Designed an interactive Power BI dashboard with KPI cards, charts, and slicers.
6. **Insight Generation:** Analyzed churn patterns to identify potential customer retention opportunities.

## 📊 Dashboard Features

- Total Customers
- Churned Customers
- Retained Customers
- Customer Churn Rate
- Churn analysis by contract type
- Churn patterns by internet service
- Payment method analysis
- Interactive slicers for exploring customer segments

## 💡 Key Business Insights

The dashboard helps explore:

- Which contract types are associated with higher customer churn.
- How churn varies across internet service categories.
- Whether payment methods are associated with different churn patterns.
- Which customer segments may need additional retention efforts.
- How customer retention compares with customer loss.
